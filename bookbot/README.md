BookBot

My BookBot is a small command-line Python project that analyzes a text file and prints out some basic stats about it. You give it a book (or any .txt file), and it tells you how many words it has and how often each letter shows up, sorted from most common to least common.

The goal of the project was to practice working with files, dictionaries, sorting data, and command-line arguments, while keeping the code clean and organized.

What it does
	•	Takes a text file path as a command-line argument
	•	Validates input and shows a usage message if something’s wrong
	•	Counts the total number of words in the text
	•	Counts how often each alphabetical character appears
	•	Outputs a formatted report to the terminal


I built this project to get more comfortable with core Python concepts like file I/O, dictionaries, sorting, and building simple command-line tools. It also helped to reinforce separating concepts into helper functions instead of dumping everything into one file.
